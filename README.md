# 基于 STM32 的多传感器姿态采集与伺服控制系统

> MCU: STM32F103C8T6 | 传感器: MPU6050 | 执行器: SG90 舵机 | 显示: 0.96" OLED | 架构: 非阻塞时间片轮询

## 1. 引脚接线表

### 1.1 总览

| STM32 引脚 | 复用功能 | 连接模块 | 信号 |
|-----------|---------|---------|------|
| **PA0** | TIM2_CH1 | SG90 舵机 | PWM (50Hz) |
| **PA1** | ADC1_CH1 | 模拟传感器 | 0~3.3V 模拟输入 |
| **PA9** | USART1_TX | USB-TTL 模块 | 串口发送 → 模块 RX |
| **PA10** | USART1_RX | USB-TTL 模块 | 串口接收 ← 模块 TX |
| **PB10** | GPIO | MPU6050 + OLED | I2C SCL (共享总线) |
| **PB11** | GPIO | MPU6050 + OLED | I2C SDA (共享总线) |
| **PB12** | EXTI12 | EC11 编码器 | A 相 (CLK) |
| **PB13** | EXTI13 | EC11 编码器 | B 相 (DT) |
| **PB14** | GPIO | EC11 编码器 | SW 按键 (模式切换) |

### 1.2 SG90 舵机

| 舵机引线 | 颜色 | 连接 | 说明 |
|---------|------|------|------|
| 信号 | 橙 | **PA0** | 500~2500µs 脉冲, 占空比决定角度 |
| 电源 | 红 | **外部 5V** | ⚠️ 禁止从 STM32 3.3V 取电 |
| 地 | 棕 | **GND** | 须与 STM32 共地 |

### 1.3 MPU6050 (I2C 地址 0x68)

| MPU6050 | STM32 / 电源 | 说明 |
|---------|-------------|------|
| VCC | 3.3V | 不可接 5V |
| GND | GND | — |
| SCL | PB10 | 模块板载 4.7kΩ 上拉 |
| SDA | PB11 | 模块板载 4.7kΩ 上拉 |
| AD0 | GND | 接地 → 地址 0x68 |

### 1.4 0.96" OLED (I2C 地址 0x3C)

| OLED | STM32 / 电源 | 说明 |
|------|-------------|------|
| VCC | 3.3V | — |
| GND | GND | — |
| SCL | PB10 | 与 MPU6050 共享总线 |
| SDA | PB11 | 与 MPU6050 共享总线 |

### 1.5 USB-TTL (VOFA+ 串口波形)

| USB-TTL | STM32 | 说明 |
|---------|-------|------|
| RX | PA9 (TX) | 交叉连接 |
| TX | PA10 (RX) | 交叉连接 |
| GND | GND | 必须共地 |
| 5V/3.3V | 不接 | 由 USB 自身供电 |

### 1.6 EC11 旋转编码器

| EC11 | STM32 | 说明 |
|------|-------|------|
| A (CLK) | PB12 | 下降沿触发中断 |
| B (DT) | PB13 | 方向判断 |
| C | GND | 公共端 |
| VCC | 3.3V | 模块板载上拉供电 (A/B/C/GND/VCC 五脚布局) |
| SW | **PB14** | 短按切换模式: RUN→调Kp→调Ki→调Kd |

> 注: 部分 EC11 模块 (A/B/C/GND/VCC 五脚布局) 未引出按键引脚。此时 PB14 悬空 (内部上拉保持高电平)，系统默认工作在 RUN 模式；需要切换调参模式时，可用导线将 PB14 短暂接 GND 模拟按键。

> **引脚冲突检查结果**: 全部通过，无 GPIO 或外设复用冲突。

## 2. 硬件风险预警

### 2.1 舵机大电流导致 MCU 复位 (最严重)

| 现象 | 原因 | 解决方案 |
|------|------|---------|
| 舵机一动，STM32 就复位 | SG90 堵转电流 >750mA，从 STM32 3.3V 取电直接拉低 VDD | ① 舵机必须外接独立 5V/2A 电源 ② 舵机 GND 与 STM32 GND 共地 ③ 5V 电源端并联 470µF 电解电容 + 0.1µF 瓷片电容 |
| USB 口供电时舵机一动就复位 | 电脑 USB 口限流 500mA，舵机 + OLED + MPU6050 总和超限 | ① 使用外部 5V 适配器 ② 或用带外部供电的 USB HUB |

### 2.2 I2C 总线上拉缺失

| 现象 | 原因 | 解决方案 |
|------|------|---------|
| MPU6050 WHO_AM_I 返回 0xFF 或 0x00 | SDA/SCL 无上拉电阻，总线无法回到高电平 | ① 确认模块自带 4.7kΩ 上拉 ② 若无，在 SDA/SCL 各接 4.7kΩ 到 3.3V |
| 单个模块正常，并联后通信失败 | 两个模块自带上拉 → 等效电阻变小 → 驱动电流不足 | 软件 I2C 已降速至 ~100kHz 标准模式，确保稳定 |

### 2.3 MPU6050 电压超限

| 现象 | 原因 | 解决方案 |
|------|------|---------|
| MPU6050 发烫 / 读数全零 | 接了 5V，芯片烧毁 | MPU6050 **必须 3.3V**，不可接 5V |
| 模块有 LDO 但读数异常 | LDO 输出纹波大 | 在模块 VCC-GND 间加 0.1µF 去耦电容 |

### 2.4 OLED 不亮

| 现象 | 原因 | 解决方案 |
|------|------|---------|
| OLED 全黑无任何显示 | 电荷泵未开启 / I2C 地址错误 | 确认初始化序列中 0x8D→0x14 已执行；确认地址为 0x3C |
| OLED 花屏 / 乱码 | 初始化延时不足 | SSD1306 上电后需 ≥100ms 等待 VDD 稳定 |

### 2.5 串口无数据

| 现象 | 原因 | 解决方案 |
|------|------|---------|
| VOFA+ 无波形 | 接线交叉错误 | PA9 (TX) → USB-TTL 的 RX，不是 TX→TX |
| 乱码 | 波特率不匹配 | 确认 115200-8-N-1，VOFA+ 协议选择 FireWater |

## 3. 数据流架构

```
┌──────────┐  I2C 100kHz  ┌──────────────┐   100Hz    ┌─────────────────┐
│ MPU6050  │──────────────→│ 互补滤波      │──────────→│ PID (位置式)     │
│ 125Hz    │               │ α=0.98       │           │ Kp=2.0 Ki=0.05  │
│          │               │ pitch / roll │           │ Kd=0.5          │
└──────────┘               └──────────────┘           └────────┬────────┘
                                                               │ 50Hz
┌──────────┐  EXTI 中断                                     ┌──▼─────────────┐
│ EC11     │────────────────────→ 目标角度 ±2°/脉冲          │ SG90 舵机       │
│ 编码器   │                                               │ PWM 50Hz       │
└──────────┘                                               │ 0~180°         │
                                                           └────────────────┘
┌──────────┐  DMA Channel4    ┌──────────┐
│ USART1   │─────────────────→│ VOFA+    │  7 通道 FireWater CSV 波形
│ 115200   │  50ms / 帧       │ 上位机   │  pitch / roll / acc / gyro / PID / ADC
└──────────┘                  └──────────┘
```

## 4. 软件架构

| 模块 | 技术点 |
|------|--------|
| **时间基准** | SysTick 1ms 中断, `volatile uint32_t` 无符号溢出安全 |
| **任务调度** | 5路非阻塞轮询: 10ms / 20ms / 50ms / 200ms / 1000ms |
| **I2C** | GPIO 开漏输出软件模拟, ~100kHz, 多从机共享总线 |
| **姿态解算** | 一阶互补滤波: `angle = α*(angle+gyro·dt) + (1-α)*accel_angle` |
| **PID 控制** | 位置式, 抗积分饱和, 输出钳位 0~180° |
| **串口** | USART1 寄存器配置 + DMA1_Channel4 非阻塞发送 + VOFA+ FireWater CSV (7通道) |
| **消抖** | 编码器 5ms 软件消抖, 时间戳判断 |
| **非阻塞设计** | 无 delay_ms() 阻塞调用，全部基于 SysTick 时间判断 |
