# 系统调试与故障排查手册

## 1. 模块化 Bring-up 流程

> 原则: 每次只增加一个模块，验证通过后再接下一个。严禁一次性连接全部模块后上电。

### 1.1 Stage 0: 最小系统验证

**目标:** 确认 MCU 正常启动、SWD 烧录可用、串口通信正常。

**接线:**

| ST-Link / USB-TTL | STM32F103C8T6 |
|-------------------|---------------|
| SWCLK | SWCLK |
| SWDIO | SWDIO |
| GND | GND |
| USB-TTL RX | PA9 (USART1_TX) |
| USB-TTL TX | PA10 (USART1_RX) |

**验证步骤:**
1. Keil MDK → Rebuild → 确认 0 Error, 0 Warning
2. Download → 复位 MCU
3. 串口终端 (115200-8-N-1) 应输出:

```
========================================
  STM32 Attitude & Servo Control System
  MCU: STM32F103C8T6 @ 72MHz
========================================
[INIT] IWDG watchdog...
[OK]   IWDG enabled, timeout ~1s
```

**失败排查:**
- 无输出 → 检查 TX (PA9) 是否连接到 USB-TTL 的 RX (交叉连接)
- 乱码 → 波特率不匹配，确认 115200

---

### 1.2 Stage 1: I2C 总线验证

**增加接线:**

| 模块 | STM32 |
|------|-------|
| OLED VCC | 3.3V |
| OLED GND | GND |
| OLED SCL | PB10 |
| OLED SDA | PB11 |

**验证步骤:**
1. 烧录，串口应在 `< 2s` 内打印 `[OK] MPU6050 WHO_AM_I = 0x68`
2. OLED 显示 "System Ready" 及姿态数据
3. 检查 OLED 右下角心跳指示 (`*` 以 1Hz 闪烁)

**WHO_AM_I 返回 0xFF 或 0x00 时:**
- 万用表测量 SDA/SCL 对 VCC 电阻 → 应约为 4.7kΩ (模块板上拉)
- 检查 PB10→SCL, PB11→SDA 是否接反
- 断开 OLED，仅保留 MPU6050，排除总线多从机冲突

---

### 1.3 Stage 2: 传感器数据验证

**目标:** 确认 MPU6050 原始数据正确，姿态解算输出合理。

**验证步骤:**
1. 传感器水平放置 → OLED 显示 `P: 0.0 R: 0.0` (误差 ±2° 内)
2. 缓慢前倾 → pitch 正值增大
3. 缓慢左倾 → roll 正值增大
4. 连接 VOFA+ → JustFloat → 7 通道 → Little Endian → 观察 ch0/ch1 波形

**角度漂移 (静止时缓慢变化):**
- α 值过大 (如 0.995) → 减小至 0.96~0.98
- 陀螺仪零偏未校准 → 在静止时读取 gyro 均值，初始化时减去

**角度跳动:**
- DLPF 带宽过高 → 检查 CONFIG 寄存器 (0x1A)，确认值为 0x06 (5Hz)
- 供电纹波 → 在 MPU6050 VCC-GND 间加 0.1µF 去耦电容

---

### 1.4 Stage 3: 舵机 PWM

**增加接线:**

| SG90 舵机 | 连接 |
|-----------|------|
| 橙 (信号) | PA0 |
| 红 (电源) | **外部 5V** (严禁接 STM32 3.3V) |
| 棕 (GND) | STM32 GND (必须共地) |

> 外部 5V 电源需 ≥ 2A。推荐在电源输出端并联 470µF 电解电容 + 0.1µF 瓷片电容。

**验证步骤:**
1. 上电 → 舵机自动归中 (90°)
2. 旋转编码器 → 舵机平滑跟随
3. 倾斜传感器 → 舵机动态跟踪角度变化

---

### 1.5 Stage 4: PID 参数整定

**方法: Ziegler-Nichols 临界比例度法 (工程简化版)**

1. 设 $K_i = 0, K_d = 0$
2. 逐步增大 $K_p$，直到系统出现等幅振荡，记录临界增益 $K_u$ 和振荡周期 $T_u$
3. 按规则计算:

| 控制类型 | $K_p$ | $K_i$ | $K_d$ |
|---------|-------|-------|-------|
| P | $0.5 K_u$ | — | — |
| PI | $0.45 K_u$ | $0.54 K_u / T_u$ | — |
| PID | $0.6 K_u$ | $1.2 K_u / T_u$ | $0.075 K_u \cdot T_u$ |

**在线调参 (本工程支持):**

短按编码器 SW 按键 (PB14) 循环切换模式:

```
MODE_RUN    → 正常运行，编码器调 setpoint
MODE_TUNE_KP → 旋转编码器调节 Kp (步长 0.1)
MODE_TUNE_KI → 旋转编码器调节 Ki (步长 0.01)
MODE_TUNE_KD → 旋转编码器调节 Kd (步长 0.05)
```

OLED 行 6 实时显示当前模式及参数值。VOFA+ 可同步观察 PID 输出 (ch5) 的响应变化。

**调参参考:**

| 现象 | 根因 | 调整方向 |
|------|------|---------|
| 响应迟缓 | Kp 不足 | ↑ Kp |
| 持续振荡 | Kp 过大 | ↓ Kp |
| 存在稳态误差 | Ki 为零或过小 | ↑ Ki |
| 超调后缓慢回落 | 积分饱和 | ↓ Ki 或 ↓ integral_limit |
| 到位后高频微振 | Kd 放大噪声 | ↓ Kd 或对传感器做低通 |
| 跟踪滞后显著 | Kp 不足或 Kd 过大 | ↑ Kp / ↓ Kd |

## 2. 异常排查

### 2.1 供电跌落复位

**现象:** 舵机动作瞬间 MCU 复位 (串口输出 Reset Source，OLED 闪屏，心跳停止)。

**根因:** SG90 堵转电流 >750mA。若从 STM32 3.3V LDO 取电，LDO 输出电流不足 → 电压跌落至 BOR 阈值 (~2.4V) 以下 → 系统复位。

**诊断:**
1. 万用表监测 STM32 3.3V 引脚在舵机启动时的电压
2. 电压 < 3.0V → 确认供电不足

**解决方案:**
1. 舵机必须使用独立 5V/2A 电源，与 MCU 供电物理隔离
2. 5V 输出端并联 470µF 电解 (储能) + 0.1µF 瓷片 (高频去耦)
3. MCU 端每个 VDD 引脚就近放置 0.1µF 瓷片电容
4. 所有模块的 GND 必须单点共地 (星形接地)

**进阶:** 若必须使用同一电源，在舵机供电回路串联 NTC 热敏电阻 (冷态 10Ω，热态 <1Ω) 抑制启动浪涌。

---

### 2.2 I2C 总线通信故障

**现象:** MPU6050 WHO_AM_I 返回 0xFF，OLED 不亮，程序卡在 I2C 初始化。

**排查路径:**

| 步骤 | 检查项 | 方法 |
|------|--------|------|
| 1 | 物理接线 | 万用表通断档验证 SDA/PB11, SCL/PB10 连通性 |
| 2 | 供电 | 测量各模块 VCC-GND = 3.3V ±0.1V |
| 3 | 上拉电阻 | 断电后测 SDA-VCC = 4.7kΩ (允许 2.2~10kΩ) |
| 4 | 地址冲突 | 仅保留 MPU6050，AD0 接 GND → 地址 0x68 |
| 5 | 时序裕度 | 增大 I2C_Delay() 延时 (nop 循环计数 ×2) |
| 6 | 从机故障 | 替换模块，单一变量法定位 |

**STM32F1 硬件 I2C BUSY 锁死:**

若使用硬件 I2C 替代本工程的软件 I2C，需注意: STM32F1 的 I2C 外设在从机异常复位或总线干扰后，BUSY 位可能永久置 1。此时必须在 I2C_Init 中执行软件复位序列:

```c
RCC_APB1PeriphResetCmd(RCC_APB1Periph_I2C1, ENABLE);
RCC_APB1PeriphResetCmd(RCC_APB1Periph_I2C1, DISABLE);
```

本工程使用软件 I2C，此问题不适用。

### 2.3 PID 控制发散

| 现象 | 诊断 | 修正 |
|------|------|------|
| 等幅振荡 | $K_p$ 过大 | 减半 $K_p$，观察 5 个周期 |
| 发散 (振幅越来越大) | $K_i$ 过大或 integral_limit 过高 | 降低 $K_i$，限制 integral_limit |
| 到位后微振 (buzzing) | $K_d$ 放大传感器噪声 | 降低 $K_d$，或对输入做低通 |
| 阶跃响应超调 >50% | 积分饱和 | 减小 integral_limit，或切换 setpoint 时清零积分 |
| 稳态误差 >3° | $K_i$ 不足 | 增大 $K_i$，每次 +0.01 |
| 舵机不响应 | 输出超出 0~180° 范围 | 检查 output_min/max 钳位 |

**VOFA+ 辅助诊断:**

| 波形特征 | 对应问题 |
|---------|---------|
| ch0 (滤波角度) 与 ch2 (原始角度) 差异大 | 互补滤波 α 值偏高 |
| ch5 (PID 输出) 频繁达到上下限 | 输出范围不足或 Kp 过大 |
| ch3/ch4 (陀螺仪) 噪声幅值 > 5°/s | 机械振动耦合，加固传感器安装 |

### 2.4 OLED 显示异常

| 现象 | 根因 | 解决 |
|------|------|------|
| 无显示 (全黑) | 电荷泵未开启 | 确认 0x8D→0x14 序列已执行 |
| 无显示 (全黑) | I2C 地址错误 | 测量 SA0 引脚电平: GND→0x3C, VCC→0x3D |
| 花屏/移位 | 初始化延时不足 | SSD1306 上电后 VDD 稳定需 ≥100ms |
| 局部缺行 | 页地址配置错误 | 检查 OLED_SetCursor page 参数 < 8 |
| 亮度过低 | 对比度寄存器 | 0x81 命令后跟值改为 0xFF |

---

### 2.5 串口数据异常

| 现象 | 排查 |
|------|------|
| VOFA+ 无波形 | 协议: JustFloat → Little Endian → 通道数: 7 |
| 帧断断续续 | 检查 DMA 传输是否完成: UART1_DMA_Update 是否被正常调用 |
| 部分通道为 0 | 对应传感器数据未更新，检查 10ms 任务是否正常执行 |
| HEX 显示正确但波形不对 | 字节序: STM32 为 little-endian，与 VOFA+ 设置一致 |

### 2.6 编码器计数异常

| 现象 | 根因 | 修正 |
|------|------|------|
| 旋转无反应 | EXTI 中断未使能 | 检查 NVIC 配置 |
| 转 1 格跳多格 | 消抖时间不足 | 增大 ENCODER_DEBOUNCE_MS |
| 只能单向计数 | B 相未连通 | 测量 PB13 电平是否随旋转跳变 |
| 方向判断反了 | A/B 相接反 | 交换 A/B，或修改 ISR 中 `Bit_RESET` 判断分支 |
